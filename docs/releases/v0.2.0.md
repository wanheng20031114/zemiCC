## zemiCC 0.2.0

首个可直接安装的 Windows 桌面版本。

- **安装版**：下载 `zemiCC-Setup-0.2.0-x64.exe`，安装后从桌面或开始菜单启动，可固定到任务栏。
- **免安装版**：解压 `zemiCC-0.2.0-win-x64.zip` 到固定文件夹，双击 `zemiCC.exe`。请保留整个文件夹。
- 内置 Electron 与 Claude Agent 运行时，无需安装 Node.js、npm 或全局 Claude Code。项目自身的开发工具仍需安装；Windows shell 工具建议安装 Git for Windows。
- 独立应用名称、图标、任务栏身份和稳定的启动路径。
- 项目与脱敏会话保存在 `%APPDATA%\zemiCC\workspace\workspace.json`，更新应用时保留。API key 仍仅在内存中，每次退出后需重新输入。
- 保留项目自动权限、危险操作确认、逐次确认模式、流式工具和界面缩放。

支持 Windows 10/11 x64。此版本未使用代码签名证书，Windows 可能显示未知发布者提示。`SHA256SUMS.txt` 提供两个下载文件的 SHA-256 校验值。

zemiCC 是独立界面，不是 Anthropic 官方应用。Claude Agent SDK 及原生运行时适用 Anthropic 条款，API 费用由使用者承担。
