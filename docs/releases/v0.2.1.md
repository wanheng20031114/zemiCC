## zemiCC 0.2.1

全新「轨道 Z」图标：几何 Z、冰青色轨道与暖色星点，搭配深石墨底色。

- 统一应用、任务栏、桌面快捷方式、安装包、聊天头像和浏览器图标。
- Windows 图标包含 16–256 像素的 7 个尺寸，适配任务栏与高分屏。
- 图标由同一份 SVG 生成，避免应用内外版本不一致。

下载 `zemiCC-Setup-0.2.1-x64.exe` 更新安装，或完整解压 `zemiCC-0.2.1-win-x64.zip` 使用免安装版。更新保留项目、会话与权限偏好，密钥仍仅在内存中。

支持 Windows 10/11 x64；安装包未签名。文件校验值见 `SHA256SUMS.txt`。
