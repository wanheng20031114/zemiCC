## zemiCC 0.2.2

全新樱花图标。五片圆润花瓣保留樱花的 V 形缺口，主体放大，并加入花心细线与节点；配色采用冰青、银白与深石墨。

- 更新应用、任务栏、桌面快捷方式、安装包、聊天头像和浏览器图标。
- Windows 图标包含 16–256 像素的 7 个尺寸，所有图标来自同一份 SVG。

下载 `zemiCC-Setup-0.2.2-x64.exe` 更新安装，或完整解压 `zemiCC-0.2.2-win-x64.zip` 使用免安装版。更新保留项目、会话与权限偏好，密钥仍仅在内存中。

支持 Windows 10/11 x64；安装包未签名。文件校验值见 `SHA256SUMS.txt`。
