## zemiCC 0.3.0

Claude 现在可以直接使用你配置的 MCP 工具。

- 左侧新增 **MCP 服务器**：添加、编辑、启停、移除，以及标准 `mcpServers` JSON 导入。
- 支持本地 stdio、远程 Streamable HTTP 和 SSE；连接测试会列出可用工具，无需调用模型。
- 工具调用使用 Claude Agent SDK 原生 MCP 与自动权限审核，需要时才请求人工确认。
- 环境变量和认证请求头的值仅保留在内存，重启后重新填写；连接配置与字段名称会保留。
- 空闲对话修改服务器后，下条消息生效并保留 SDK 上下文。继续保留长任务无应用层轮数或金额上限的行为。

本地 MCP 可能需要另行安装 Node.js、uv 或服务自身运行环境。远程服务支持请求头认证，暂未提供浏览器 OAuth 登录流程。请仅接入信任的服务器。

更新会保留项目与会话，重启后需重新输入 API key。提供 Windows x64 安装版、ZIP 免安装版与 SHA-256 校验文件。
