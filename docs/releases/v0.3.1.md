## zemiCC 0.3.1

Agent 工作时，界面也可以继续操作。

- 输入框保持可编辑，发送箭头可随时补充信息，消息直接进入当前 SDK 会话。停止按钮单独保留。
- 连续补充消息按顺序送达，显示待接收状态；发送过程中继续输入的草稿不会被清空。停止会取消未送达消息。
- MCP 可以随时编辑、导入、测试或启停。配置立即保存，在当前任务及排队消息完成后更新连接，避免打断正在使用的工具。
- 权限模式可在执行中切换，已有确认卡片仍需处理；模型选择保持可编辑，在下一条消息发送时应用。

继续使用用户自己的 API key，密钥只在内存中。保留无应用层轮数或金额上限的长任务行为。更新会保留项目与会话，重启后需重新输入 key。
