# zemiCC v0.3.3

对话现在支持图片。点击输入框左下角的图片按钮、粘贴截图，或拖入图片即可添加；支持缩略图移除、点击放大、纯图片消息，以及 Agent 工作时继续补图。

- 使用 Claude Agent SDK 原生图片内容，模型可以实际读取图像。
- PNG / JPEG / WebP / GIF（首帧），每条消息最多 5 张；较大图片自动缩小并移除额外元数据。
- 图片随对话保存在本机，重启后可查看并恢复最近的图片上下文；删除会话会清理不再被引用的图片。
- 上传和查看沿用本机会话认证，不接受远程地址或任意文件路径。API key 与 MCP 凭据仍仅在内存中。

验证：29 项自动化测试，覆盖实际图片块、运行中补充、恢复、格式与大小限制、访问认证，以及原有的回复去重、权限和 MCP 回归。

已实测图片选择、剪贴板粘贴、预览与移除；真实模型识图和重启后图片上下文恢复通过。

更新保留项目、对话与权限选择。重启应用后需要重新输入 API key。安装版、免安装 ZIP 和 SHA-256 校验文件见本页附件。
