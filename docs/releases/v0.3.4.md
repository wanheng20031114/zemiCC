# zemiCC v0.3.4

只修复两项已复现的问题：

- 恢复对话时，同一附件在多条历史消息中反复引用，或同时出现在当前消息中，会重复发送图片内容。现在每个相同附件引用只发送一次，历史文字和当前附件仍完整保留，避免无用的图片 token 消耗。
- SDK 异常结果可能返回空的累计用量。现在保留之前已经记录的 token 与费用；带有实际用量的错误结果仍正常计入，避免显示数值回退。

验证：31 项自动化测试，包括先复现再修复的两项回归测试。正常会话复用、上下文恢复策略、权限审核、MCP 和图片清晰度保持原有行为。

更新保留项目、对话、图片及权限选择。重启应用后需重新输入 API key。
